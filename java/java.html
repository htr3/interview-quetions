Why is Java called platform independent?

Easy⭐ VIcore▼

  • JVM
  • JVM interprets or JIT

Brief explanation

In simple terms: This explains why is Java called platform independent. Source compiles to bytecode (.class), not CPU-specific machine code.

Source compiles to bytecode (.class), not CPU-specific machine code. Any OS with a JVM runs the same bytecode.

Flow

  1. Write .java
  2. javac → bytecode
  3. JVM interprets or JIT-compiles to native code

Nuance: Java is platform-independent; the JVM is platform-specific (install Windows/Linux JVM).
