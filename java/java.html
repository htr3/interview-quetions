Core Java & OOP

Platform, == vs equals, OOP pillars, immutability — fundamentals.

10 questions in this section

Why is Java called platform independent?

Easy⭐ VIcore▼

Answer

Source compiles to bytecode (.class), not CPU-specific machine code. Any OS with a JVM runs the same bytecode.

Flow

  1. Write .java
  2. javac → bytecode
  3. JVM interprets or JIT-compiles to native code

Nuance: Java is platform-independent; the JVM is platform-specific (install Windows/Linux JVM).

JDK vs JRE vs JVM?

Easycore▼

Answer

  • JVM — runs bytecode
  • JRE — JVM + libraries (legacy term)
  • JDK — JRE + javac, javadoc, tools for development

You develop with JDK; production containers often need JRE/runtime only.

== vs equals() — when to use which?

Easy⭐ VIcore▼

Rule

== on objects compares references. equals() compares content when overridden.

Example

String a = new String("hi");
String b = new String("hi");
a == b;       // false
a.equals(b);  // true

String x = "hi";
String y = "hi";
x == y;       // true — string pool

Primitives

For int, boolean use == only.

What are the four pillars of OOP?

Easy⭐ VIcore▼

Encapsulation

Hide data (private fields), expose behavior (public methods).

Inheritance

IS-A reuse — prefer composition when possible.

Polymorphism

Same interface, different behavior — overriding.

Abstraction

Hide how, show what — interfaces/abstract classes.

Example

public interface PaymentService {
  void pay(BigDecimal amount);
}
// CreditCardPayment, WalletPayment implementations

Spring services depend on interfaces (DIP).

Interface vs abstract class?

Easycore▼

Interface

Contract; multiple inheritance; default/static methods (Java 8+). No state (until records/patterns evolve).

Abstract class

Shared fields + partial implementation; single inheritance.

Prefer interface for API boundaries between modules.

Method overloading vs overriding?

Easycore▼

Overloading

Same class, same method name, different parameters — compile-time polymorphism.

Overriding

Subclass replaces parent method — runtime polymorphism; use @Override.

Example

class ReportService {
  void export(String id) { }
  void export(String id, String format) { } // overload
}
class PdfReport extends ReportService {
  @Override void export(String id) { /* PDF */ }
}

Composition over inheritance?

Mediumcore▼

Answer

Instead of extending a fat base class, wrap/has-a collaborator. Flexible, avoids fragile base class hierarchy.

Example

class OrderService {
  private final NotificationSender sender; // composed
  OrderService(NotificationSender sender) {
    this.sender = sender;
  }
}

Favor has-a over is-a when behavior stacks combine.

Does Java pass by reference or value?

Medium⭐ VIcore▼

Answer

Always pass by value — copy of reference for objects. You cannot swap two references from caller side.

Example

void swap(int[] a, int[] b) {
  int[] temp = a;
  a = b;  // only local copies change
  b = temp;
}

Mutating object state through reference affects caller; reassigning parameter does not.

How do you make a class immutable?

Medium⭐ VIcore▼

Answer

  • final class, private final fields
  • No setters
  • Defensive copy of mutable inputs (List, Date)
  • Return copies from getters

Example

public final class Money {
  private final BigDecimal amount;
  public Money(BigDecimal amount) {
    this.amount = amount;
  }
  public BigDecimal getAmount() { return amount; }
}

Immutable objects are thread-safe — great for DTOs and cache keys.

Records and sealed classes (Java 17+)?

Mediumcore▼

Record

Brief immutable data carrier — auto equals/hashCode/toString.

Example

public record ReportDto(String id, String status) { }

Sealed

Restrict which classes extend — exhaustive switch in pattern matching.

Strings, equals & keywords

String builders, hashCode contract, final/finally, autoboxing.

6 questions in this section

String vs StringBuilder vs StringBuffer?

Easystring▼

Answer

  • String — immutable; every concat may create new object
  • StringBuilder — mutable, fast, not thread-safe
  • StringBuffer — synchronized legacy

Example

StringBuilder sb = new StringBuilder();
for (String row : rows) {
  sb.append(row).append(",");
}
String csv = sb.toString();

Use StringBuilder in loops building large text (report CSV export).

String pool and intern()?

Mediumstring▼

Answer

Literal strings live in pool; intern() returns pooled instance. Saves memory but pool is global — don't intern unbounded user input.

Example

String a = "report";
String b = "report";
a == b; // true — same pool entry

equals() and hashCode() contract?

Medium⭐ VIstring▼

Rule

If a.equals(b) then a.hashCode() == b.hashCode(). Override both together for HashMap keys.

Example

@Override public boolean equals(Object o) {
  if (this == o) return true;
  if (!(o instanceof User u)) return false;
  return Objects.equals(email, u.email);
}
@Override public int hashCode() {
  return Objects.hash(email);
}

Broken contract → HashMap duplicates or lost keys.

final vs finally vs finalize?

Mediumstring▼

Answer

  • final — can't reassign variable; can't override method; can't extend class
  • finally — runs after try/catch (cleanup)
  • finalize — deprecated GC hook — don't use

Example

try (Connection conn = dataSource.getConnection()) {
  // auto-close — prefer try-with-resources
}

Autoboxing and pitfalls?

Easystring▼

Answer

int ↔ Integer automatic. Null Integer unboxed → NPE. == on Integer outside -128..127 cache compares references.

Example

Integer a = 200, b = 200;
a == b; // false
Integer x = 100, y = 100;
x == y; // true — cached

What does the JVM JIT compiler do?

Mediumstring▼

Answer

Hot methods compiled to native code after profiling — faster than interpret. Cold start after deploy slower until warm-up.

Vodafone/Optima: post-deploy smoke helps JIT + connection pool warm-up.

Collections Framework

List, Set, Map internals, iterators, Optional, sorting.

9 questions in this section

ArrayList vs LinkedList?

Easycollections▼

Answer

ArrayList: dynamic array, O(1) get, amortized O(1) append end. LinkedList: O(n) get, O(1) insert at known node.

Default: ArrayList unless you need Deque operations at both ends.

Example

List reports = new ArrayList<>();
reports.add("R001");
String first = reports.get(0);

HashMap internal working (Java 8+)?

Hard⭐ VIcollections▼

Structure

Array of buckets; index = (n-1) & hash. Collision: linked list → red-black tree if chain > 8 and table ≥ 64.

put flow

  1. Compute hash
  2. Find bucket
  3. Same key (equals) → replace value
  4. Else add to chain/tree

Load factor

0.75 → resize double, rehash.

HashMap vs Hashtable vs ConcurrentHashMap?

Medium⭐ VIcollections▼

Answer

  • HashMap — not thread-safe, one null key
  • Hashtable — legacy synchronized — slow
  • ConcurrentHashMap — fine-grained locks/CAS — use for shared caches

Example

Map cache = new ConcurrentHashMap<>();
cache.put(id, report);

HashSet vs TreeSet?

Mediumcollections▼

Answer

HashSet: O(1) add/contains, no order. TreeSet: Red-black tree, sorted, O(log n). Use TreeSet when you need range queries or sorted iteration.

HashMap of List — common pattern and pitfall?

Medium⭐ VIcollections▼

Answer

Group records by key. Pitfall: mutating list from getter without checking null.

Example

Map> byAccount = new HashMap<>();
byAccount.computeIfAbsent(accountId, k -> new ArrayList<>()).add(report);

computeIfAbsent is cleaner than get/put null checks.

Comparable vs Comparator?

Mediumcollections▼

Answer

Comparable — natural order inside class (compareTo). Comparator — external, multiple sort orders.

Example

reports.sort(Comparator.comparing(Report::getCreatedAt).reversed());

fail-fast vs fail-safe iterators?

Hardcollections▼

fail-fast

ArrayList iterator throws ConcurrentModificationException if collection structurally modified during iteration (except iterator.remove).

fail-safe

CopyOnWriteArrayList iterates snapshot — safe under concurrent reads.

Example

for (String id : ids) {
  if (expired(id)) ids.remove(id); // throws on ArrayList
}
ids.removeIf(this::expired); // safe

Queue and Deque in Java?

Easycollections▼

Answer

Queue: FIFO — LinkedList, PriorityQueue. Deque: double-ended — ArrayDeque for stack/queue. Used in BFS, task scheduling.

Optional — when and when not?

Mediumcollections▼

Good

Return type when value may be absent — forces caller to handle.

Bad

Fields, method parameters, collections of Optionals.

Example

public Optional findById(String id) {
  return repo.findById(id);
}
Report r = findById(id).orElseThrow(() -> new NotFoundException(id));

Multithreading & Concurrency

Thread safety, pools, volatile, atomics, CompletableFuture.

8 questions in this section

How do you make code thread-safe?

Hard⭐ VIconcurrency▼

Strategies

  • Immutability (best)
  • synchronized / ReentrantLock on critical sections
  • ConcurrentHashMap, AtomicLong
  • Stateless Spring beans — no mutable instance fields

Deadlock

Two locks opposite order → deadlock. Fix: consistent lock ordering, tryLock timeout.

Thread pool / ExecutorService?

Medium⭐ VIconcurrency▼

Answer

Reuse threads instead of new Thread() per task. Configure core/max pool and bounded queue.

Example

ExecutorService pool = Executors.newFixedThreadPool(8);
pool.submit(() -> generateReport(id));
// Spring @Async uses TaskExecutor — configure queue size

Unbounded queue + slow tasks → OOM.

Callable vs Runnable?

Mediumconcurrency▼

Answer

Runnable no return value. Callable returns result and throws checked exceptions — used with Future/ExecutorService.

Example

Future future = pool.submit(() -> buildReport(id));
Report r = future.get(30, TimeUnit.SECONDS);

What does volatile do?

Mediumconcurrency▼

Answer

Visibility across threads — reads see latest write. Does NOT make compound actions atomic (i++ still needs sync or AtomicInteger).

Example

private volatile boolean shutdown = false;
// writer thread sets true; readers see immediately

AtomicInteger vs synchronized counter?

Easyconcurrency▼

Answer

Atomics use CAS — lock-free for simple increments. Good for metrics counters.

Example

private final AtomicLong processed = new AtomicLong();
processed.incrementAndGet();

Detect and prevent deadlock?

Hardconcurrency▼

Example deadlock

Thread1: lock A then B. Thread2: lock B then A.

Prevention

  • Always acquire locks in same global order
  • tryLock with timeout
  • Reduce lock scope

ThreadLocal use case?

Mediumconcurrency▼

Answer

Per-thread variable — e.g. SimpleDateFormat (legacy), user context, correlation ID in servlet thread. Clear in finally to avoid leaks in thread pools.

Example

private static final ThreadLocal CORR = new ThreadLocal<>();
CORR.set(correlationId);
try { process(); } finally { CORR.remove(); }

CompletableFuture for async composition?

Hardconcurrency▼

Answer

Chain async steps without blocking threads — thenApply, thenCombine, exceptionally.

Example

CompletableFuture.supplyAsync(() -> fetchAccount(id))
  .thenApply(acc -> buildReport(acc))
  .exceptionally(ex -> Report.error(ex));

Java 8+ Features

Lambdas, Streams, Collectors, java.time — daily backend coding.

8 questions in this section

Java Streams API?

Medium⭐ VIjava8▼

Answer

Intermediate ops lazy: filter, map, flatMap. Terminal: collect, reduce, forEach.

Example

List codes = reports.stream()
  .filter(r -> "ACTIVE".equals(r.getStatus()))
  .map(Report::getCode)
  .distinct()
  .sorted()
  .collect(Collectors.toList());

Don't use parallel() on small lists or IO-bound work.

Lambda expressions?

Easyjava8▼

Answer

Anonymous function for functional interfaces (one abstract method): Predicate, Function, Consumer.

Example

reports.removeIf(r -> r.getEndDate().isBefore(LocalDate.now()));
Comparator byDate = Comparator.comparing(Report::getCreatedAt);

Method references?

Easyjava8▼

Forms

Class::staticMethod, instance::method, Class::new, Type[]::new.

Example

reports.forEach(System.out::println);
reports.stream().map(Report::getId);

Common Collectors?

Medium⭐ VIjava8▼

Answer

toList, toSet, toMap (watch duplicate keys), groupingBy, partitioningBy, joining.

Example

Map countByStatus = reports.stream()
  .collect(Collectors.groupingBy(Report::getStatus, Collectors.counting()));

flatMap with Optional and Stream?

Mediumjava8▼

Answer

flatMap flattens nested structure — Optional stream or List of Lists.

Example

Optional city = Optional.ofNullable(user)
  .flatMap(User::getAddress)
  .map(Address::getCity);

Default methods in interfaces?

Easyjava8▼

Answer

Add behavior to interfaces without breaking implementors — e.g. Collection.stream(). Use sparingly to avoid diamond problem ambiguity.

java.time vs old Date/Calendar?

Mediumjava8▼

Answer

Immutable, thread-safe: LocalDate, LocalDateTime, ZonedDateTime, Instant. Use for report date ranges, billing periods.

Example

LocalDate from = LocalDate.parse("2024-01-01");
boolean inRange = !date.isBefore(from) && !date.isAfter(to);

Built-in functional interfaces?

Mediumjava8▼

Answer

  • Predicate<T> — boolean test
  • Function<T,R> — transform
  • Consumer<T> — side effect
  • Supplier<T> — supply value

JVM & Memory

Heap, GC, OOM debugging, class loaders.

6 questions in this section

JVM memory areas?

Medium⭐ VIjvm▼

Answer

  • Heap — objects (Young + Old)
  • Stack — per thread frames, local vars
  • Metaspace — class metadata
  • PC registers, native stacks

StackOverflowError vs OutOfMemoryError: different areas.

How does garbage collection work?

Medium⭐ VIjvm▼

Answer

Objects unreachable from GC roots are collected. Young gen: Eden + Survivor (Minor GC). Old gen: Major/Full GC — longer pauses.

Leak

Static Map holding references forever — never collected.

Example

// leak pattern
static Map CACHE = new HashMap<>();
// fix: bounded cache, Caffeine with TTL

G1 vs ZGC — what to mention?

Hardjvm▼

Answer

G1: default for many servers, balances throughput/latency, regions. ZGC/Shenandoah: very low pause targets for large heaps. Tune with -Xmx and GC logs, not guesses.

Debugging OutOfMemoryError?

Medium⭐ VIjvm▼

Answer

  • Heap dump: -XX:+HeapDumpOnOutOfMemoryError
  • MAT/VisualVM — dominator tree
  • Common causes: memory leak, heap too small, large result set loaded to List

Vodafone reporting: paginate instead of load 1M rows to heap.

Class loaders hierarchy?

Hardjvm▼

Answer

Bootstrap → Platform → Application. Parent delegation loads core JDK classes. Custom loaders in app servers (Fuse/OSGi) — know for telco integration context.

Heap vs stack storage?

Easyjvm▼

Answer

Objects on heap; method locals and references on stack. Stack frame popped when method returns. Object may survive if referenced from heap.

Exceptions & I/O

Checked/unchecked, try-with-resources, custom exceptions.

4 questions in this section

Checked vs unchecked exceptions?

Mediumexceptions▼

Answer

Checked — must handle/declare (IOException). Unchecked — RuntimeException (NPE, IllegalArgument).

Example

try {
  Files.readString(path);
} catch (IOException e) {
  throw new ReportException("Failed to read", e);
}

Spring REST: @ControllerAdvice maps to HTTP status.

try-with-resources?

Easyexceptions▼

Answer

Auto-close resources implementing AutoCloseable — JDBC, streams.

Example

try (PreparedStatement ps = conn.prepareStatement(sql)) {
  ps.setString(1, id);
  ResultSet rs = ps.executeQuery();
}

Design custom exceptions for APIs?

Mediumexceptions▼

Answer

Domain exceptions with error code + message; map in @ControllerAdvice. Don't expose stack traces to clients.

Example

public class ReportNotFoundException extends RuntimeException {
  public ReportNotFoundException(String id) {
    super("Report not found: " + id);
  }
}

java.nio.file for file operations?

Mediumexceptions▼

Answer

Paths, Files.readString/writeString (Java 11+), walk for directories — cleaner than old File API.

Example

Path path = Path.of("/data", fileName);
String content = Files.readString(path);

Design Principles & Patterns

SOLID, singleton, factory/builder, static.

6 questions in this section

SOLID principles with examples?

Medium⭐ VIdesign▼

Answer

  • S — ReportService doesn't send email
  • O — new ExportFormat class, not if-else chain edit
  • L — subclass honors parent contract
  • I — small interfaces, not God interface
  • D — depend on PaymentGateway interface, Spring injects impl

Thread-safe singleton?

Medium⭐ VIdesign▼

Answer

Double-checked locking needs volatile. Enum singleton is simplest safe pattern.

Example

public enum ConfigHolder {
  INSTANCE;
  public Properties getConfig() { ... }
}

Spring: default bean scope is singleton per context.

Factory vs Builder pattern?

Mediumdesign▼

Factory

Hides which concrete class to instantiate.

Builder

Many optional fields — readable object creation.

Example

ReportRequest req = ReportRequest.builder()
  .accountId("A1")
  .from(LocalDate.now().minusDays(7))
  .format(Format.PDF)
  .build();

Dependency injection without Spring?

Easydesign▼

Answer

Pass dependencies via constructor — same as Spring's constructor injection, manual wiring in main/tests.

Example

ReportService service = new ReportService(new JpaReportRepository());

Liskov Substitution Principle example?

Harddesign▼

Answer

Subclass must work wherever parent expected. Violation: Square extends Rectangle but setWidth breaks height invariant.

Prefer interfaces that match real behavior subsets.

static keyword — fields, methods, blocks?

Easydesign▼

Answer

Belongs to class, not instance. Static method can't access instance fields. Static block runs once at class load. Don't abuse static mutable state in web apps (shared across requests).
