Spring Boot Core

IoC, auto-config, starters, profiles — foundation before APIs and JPA.

10 questions in this section

Spring vs Spring Boot?

Easy⭐ VIcore▼

Answer

Spring Framework is the core IoC/DI container plus modules (MVC, Data, Security). You wire XML/Java config, pick versions, embed Tomcat yourself.

Spring Boot is opinionated auto-configuration on top: starters bundle dependencies, @SpringBootApplication enables component scan + auto-config, embedded server, application.yml, Actuator. You focus on business code; Boot picks sensible defaults.

Interview line

Boot does not replace Spring — it accelerates building production-ready Spring apps with less boilerplate.

What does @SpringBootApplication do?

Medium⭐ VIcore▼

Answer

Meta-annotation combining:

  • @Configuration — bean definitions
  • @EnableAutoConfiguration — load auto-config classes from classpath (conditional on jars present)
  • @ComponentScan — scan package of main class and sub-packages for @Component, @Service, etc.

Entry point: SpringApplication.run(Main.class, args) starts embedded Tomcat and refreshes ApplicationContext.

Constructor injection — why preferred?

Easy⭐ VIcore▼

Answer

  • Dependencies explicit in constructor — easy to test (pass mocks)
  • Fields can be final — immutable, thread-safe
  • Fails fast at startup if bean missing (not NPE at runtime)
  • Avoids field injection hiding large dependency lists

Spring 4.3+: single constructor needs no @Autowired.

Bean scopes in Spring?

Mediumcore▼

Answer

  • singleton (default) — one instance per container
  • prototype — new instance each injection/getBean
  • request / session / application — web scopes

Most services are singleton. Prototype injected into singleton creates many instances — understand lifecycle.

How do you fix a circular dependency?

Hard⭐ VIcore▼

Answer

A needs B, B needs A — Spring cannot construct either first with constructor-only cycle.

Fixes (best first)

  1. Redesign — extract shared logic to third bean (best design)
  2. @Lazy on one dependency — proxy delays init
  3. Setter injection on one side (less ideal)
  4. @PostConstruct manual wiring (last resort)

What are Spring Boot starters?

Medium⭐ VIcore▼

Answer

Curated dependency BOMs: spring-boot-starter-web brings Spring MVC, Jackson, Tomcat; starter-data-jpa brings Hibernate, Hikari, transaction manager.

Starters + auto-config = add jar → features appear with properties. Parent POM manages compatible versions.

Profiles and externalized configuration?

Easycore▼

Answer

spring.profiles.active=dev loads application-dev.yml. Use for DB URLs, log levels, feature flags.

12-factor: config in environment variables overrides YAML in prod (SPRING_DATASOURCE_URL). Never commit secrets.

Fat JAR and spring-boot-maven-plugin?

Easycore▼

Answer

Plugin repackages app + dependencies into executable JAR with Main-Class: JarLauncher. Run: java -jar app.jar. Standard for Docker/K8s deployments.

How does auto-configuration work?

Mediumcore▼

Answer

Classes in META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports use @ConditionalOnClass, @ConditionalOnMissingBean, @ConditionalOnProperty.

Example: if Hikari + DataSource on classpath and no user DataSource bean → Boot creates Hikari DataSource from properties.

Layered architecture in Spring Boot?

Easy⭐ VIcore▼

Answer

  • Controller — HTTP, validation, DTO mapping
  • Service — business rules, transactions
  • Repository — persistence (JPA/JDBC)

No DB calls in controllers. DTOs at API boundary — entities stay inside service/repo layer.

Spring REST API

Controllers, HTTP, validation, errors, CORS — your Vodafone reporting APIs.

15 questions in this section

Spring MVC request flow?

Medium⭐ VIapi▼

Answer

  1. DispatcherServlet receives request
  2. HandlerMapping finds @GetMapping method
  3. HandlerAdapter invokes controller
  4. Return value → HttpMessageConverter (Jackson) → JSON
  5. Exception → @ControllerAdvice handler

@RestController vs @Controller?

Easy⭐ VIapi▼

Answer

@RestController = @Controller + @ResponseBody on every method — return type serialized to JSON/XML.

@Controller — typically returns view name for Thymeleaf; use @ResponseBody per method for APIs.

How do you design a REST controller for reports?

Medium⭐ VIapi▼

Answer

  • Resource-oriented URLs: GET /api/v1/reports/{id}, POST /api/v1/reports
  • Request/response DTOs — never expose JPA entities
  • Pagination: ?page=0&size=20
  • Consistent error body: {"code","message","fieldErrors"}
  • OpenAPI for contract with frontend

Map Vodafone pattern: controller thin, service owns SQL tuning and business rules.

Which HTTP status codes should you use?

Easyapi▼

Answer

  • 200 OK with body
  • 201 Created + Location header
  • 204 No content (delete success)
  • 400 validation / bad input
  • 401 not authenticated
  • 403 authenticated but forbidden
  • 404 resource not found
  • 409 conflict (duplicate)
  • 500 unexpected server error (log stack trace, generic message to client)

@PathVariable, @RequestParam, @RequestBody?

Easyapi▼

Answer

  • @PathVariable — part of URL path (/reports/{id})
  • @RequestParam — query string (?status=ACTIVE), optional/default values
  • @RequestBody — JSON body deserialized by Jackson to DTO

@Valid and Bean Validation on DTOs?

Medium⭐ VIapi▼

Answer

Annotate DTO: @NotBlank, @NotNull, @Size, @Email. Controller: @Valid @RequestBody CreateReportRequest req.

On failure → MethodArgumentNotValidException → handle in @ControllerAdvice → 400 with per-field messages.

When do you use ResponseEntity?

Mediumapi▼

Answer

When you need control over status code, headers, or body together — e.g. 201 Created with Location header, or conditional 304.

Simple cases: return DTO + @ResponseStatus(HttpStatus.CREATED) is enough.

@ControllerAdvice for global exception handling?

Medium⭐ VIapi▼

Answer

One class with @ExceptionHandler methods for EntityNotFoundException, validation errors, AccessDeniedException. Returns consistent JSON error schema — clients never see raw stack traces.

DTO vs Entity — why separate?

Easy⭐ VIapi▼

Answer

  • Hide internal fields (passwords, lazy relations)
  • Stable API contract when DB schema changes
  • Avoid Jackson serializing Hibernate proxies (lazy load in JSON = disaster)
  • Validation annotations on API layer only

How do you configure CORS?

Mediumapi▼

Answer

Browser blocks cross-origin calls unless server sends Access-Control-Allow-Origin. In Boot: @CrossOrigin on controller or WebMvcConfigurer.addCorsMappings — whitelist origins in prod, not * with credentials.

How does JSON serialization work?

Easyapi▼

Answer

Jackson on classpath (via starter-web) maps objects to JSON. Customize with @JsonIgnore, @JsonProperty, JavaTimeModule for LocalDateTime. Dates as ISO-8601 strings, not timestamps, for APIs.

API versioning strategies?

Mediumapi▼

Answer

  • URL path: /api/v1/reports — clearest, common at Amdocs
  • Header: Accept: application/vnd.company.v2+json
  • Query param — less RESTful

Deprecate v1 with Sunset header before removal.

How do you make POST idempotent?

Hardapi▼

Answer

Client sends Idempotency-Key header; server stores key + response in Redis/DB for 24h. Duplicate key returns same response without re-processing payment/report generation.

Critical for retries from mobile apps and message consumers.

OpenAPI / Swagger in Spring Boot?

Mediumapi▼

Answer

springdoc-openapi generates spec from controllers + annotations. UI at /swagger-ui.html. Use for contract-first reviews with frontend and API Visualizer-style tooling on your resume.

File upload endpoint?

Easyapi▼

Answer

@PostMapping(consumes = MediaType.MULTIPART_FORM_DATA_VALUE) with @RequestParam MultipartFile file. Validate size/type, virus scan, store in object storage — never executable path on server filesystem.

Spring Data JPA

Entities, transactions, N+1, pooling, migrations — persistence depth.

15 questions in this section

JPA vs JdbcTemplate / native SQL?

Medium⭐ VIjpa▼

Answer

JPA — ORM, entities, repositories, good for CRUD and object graphs. JdbcTemplate/native — full SQL control for reports, bulk updates, complex joins you tuned at Vodafone.

Hybrid is normal: JPA for writes, native query for heavy read/report paths.

What is @Entity?

Easyjpa▼

Answer

Marks class mapped to table. @Id + @GeneratedValue for PK. @Column for name/nullable. Hibernate implements JPA spec — generates SQL on persist/merge/find.

What is JpaRepository?

Easy⭐ VIjpa▼

Answer

Extends CrudRepository, PagingAndSortingRepository. Gives save, findById, delete, derived queries findByAccountIdAndStatus, @Query for JPQL/native SQL.

@Transactional — how does it work and what are pitfalls?

Medium⭐ VIjpa▼

Answer

AOP proxy starts transaction on method entry, commits on success, rolls back on unchecked exceptions. readOnly=true hints DB for read-only queries.

Pitfalls: self-invocation bypasses proxy; checked exceptions don't roll back unless configured; long transactions hold DB connections.

Why does self-invocation break @Transactional?

Hard⭐ VIjpa▼

Answer

External call goes through Spring proxy; internal this.otherMethod() does not — no transaction advice applied. Fix: move method to another @Service or inject self interface with @Lazy.

N+1 problem and how do you fix it?

Medium⭐ VIjpa▼

Problem

Load 100 orders (1 query), then lazy-load items per order (100 queries).

Fixes

  • JOIN FETCH in JPQL
  • @EntityGraph on repository method
  • DTO projection query — only columns needed
  • @BatchSize on collection

FetchType LAZY vs EAGER?

Mediumjpa▼

Answer

LAZY — load association when accessed (default collections). EAGER — always join/load — can explode result set. Prefer LAZY + explicit fetch in query for list endpoints.

Pagination with Pageable?

Medium⭐ VIjpa▼

Answer

Pageable page = PageRequest.of(pageNum, size, Sort.by("id").descending());

Page<Report> result = repo.findByAccountId(id, page); — use getContent(), getTotalElements() for UI. Never load full table into memory for grid APIs.

HikariCP connection pool tuning?

Medium⭐ VIjpa▼

Answer

spring.datasource.hikari.maximum-pool-size (often 10–30), connection-timeout, max-lifetime. Pool size ≈ concurrent DB-bound threads. Too small → threads block; too large → DB overload.

Monitor active/idle connections via Actuator metrics.

What ddl-auto setting for production?

Easyjpa▼

Answer

validate or none. Never create-drop or update in prod — Flyway/Liquibase owns schema. Hibernate validates mapping matches DB.

What is Flyway?

Mediumjpa▼

Answer

Versioned SQL migrations in db/migration/V1__init.sql. Runs on startup, tracks history table. Same schema across dev/stage/prod — required for audit-friendly telco releases.

@Version optimistic locking?

Hardjpa▼

Answer

Entity has @Version Long version. UPDATE includes WHERE version = ?; if 0 rows updated → OptimisticLockingFailureException. Prevents lost updates when two users edit same report row.

JPA cascade types — what is risky?

Hardjpa▼

Answer

CascadeType.ALL on parent→children can accidentally persist/delete entire graph. Use explicit PERSIST/REMOVE only where business requires. OrphanRemoval deletes children when removed from collection — understand before enabling.

Connection pool exhausted — causes?

Hard⭐ VIjpa▼

Answer

  • Long @Transactional methods (external API inside tx)
  • Not closing streams (try-with-resources)
  • Leak detection: enable Hikari leak detection threshold in dev
  • Thread dump + metrics: all connections in use

REQUIRES_NEW transaction propagation?

Hardjpa▼

Answer

Suspends current transaction, opens new one — commits independently. Use for audit log that must persist even if main business transaction rolls back. Overuse hurts performance and debugging.

Spring Security

JWT, OAuth2, filter chain, roles — securing telco APIs.

12 questions in this section

How do you secure a Spring Boot REST API?

Hard⭐ VIsecurity▼

Answer

  1. HTTPS everywhere
  2. Authentication: JWT or OAuth2 resource server
  3. Authorization: roles on endpoints + @PreAuthorize
  4. Input validation, rate limiting
  5. Secrets in vault/env — not git
  6. Actuator not public

Security filter chain order?

Medium⭐ VIsecurity▼

Answer

Filters run before DispatcherServlet: security context restoration → JWT/OAuth filter → authorization → controller. SecurityFilterChain bean defines which URLs are permitAll vs authenticated.

Stateless JWT authentication flow?

Medium⭐ VIsecurity▼

Answer

  1. Login → server validates credentials → issues signed JWT
  2. Client sends Authorization: Bearer <token>
  3. Filter validates signature/expiry, builds Authentication
  4. No server session — scale horizontally

Refresh tokens for long-lived mobile apps; short access token TTL.

OAuth2 resource server?

Hard⭐ VIsecurity▼

Answer

Your API validates access tokens issued by IdP (Keycloak, Azure AD). Dependency spring-boot-starter-oauth2-resource-server, configure issuer-uri, JWT validated against JWK set. Scopes map to authorities.

@PreAuthorize and method security?

Mediumsecurity▼

Answer

@EnableMethodSecurity + @PreAuthorize("hasRole('REPORT_VIEW')") on service methods — fine-grained authorization after URL-level security.

CSRF for REST APIs?

Easysecurity▼

Answer

CSRF protects cookie-based browser sessions. Stateless JWT in Authorization header → typically disable CSRF for pure APIs. If using session cookies + SPA, enable CSRF token.

How should passwords be stored?

Easysecurity▼

Answer

Never plain text. BCryptPasswordEncoder with salt per password. Compare with matches(raw, encoded). Password never in logs or API responses.

401 vs 403?

Easysecurity▼

Answer

401 Unauthorized — not authenticated (missing/invalid token). 403 Forbidden — authenticated but lacks permission. Wrong status confuses API clients and security audits.

SecurityFilterChain bean (Spring Security 6)?

Mediumsecurity▼

Answer

Replace deprecated WebSecurityConfigurerAdapter. Lambda DSL: http.authorizeHttpRequests(auth -> auth.requestMatchers("/actuator/health").permitAll().anyRequest().authenticated()).

URL security vs method security?

Mediumsecurity▼

Answer

URL rules coarse (/admin/** ROLE_ADMIN). Method security for service-layer operations shared by multiple controllers. Use both: perimeter + fine-grained.

How do you secure Actuator endpoints?

Medium⭐ VIsecurity▼

Answer

Separate management port, or Spring Security on /actuator/** — only health/prometheus for K8s SA; hide env/beans/heap dump from internet.

PII in APIs and logs?

Mediumsecurity▼

Answer

Mask MSISDN/email in logs (Fuse Logger-style). DTOs exclude sensitive fields. GDPR: purpose limitation, audit access. Never log full JWT or passwords.

Spring Actuator & Operations

Health, metrics, graceful shutdown, prod ops.

10 questions in this section

What is Spring Boot Actuator?

Medium⭐ VIactuator▼

Answer

Production-ready ops endpoints: health, metrics, info, env (careful). Dependency spring-boot-starter-actuator. Expose via management.endpoints.web.exposure.include.

Liveness vs readiness probes?

Medium⭐ VIactuator▼

Answer

  • Liveness — process up? Restart pod if fails.
  • Readiness — can accept traffic? DB/upstream OK? Remove from load balancer if fails.

K8s: /actuator/health/liveness and readiness (Boot 2.3+ probes).

Custom HealthIndicator?

Mediumactuator▼

Answer

Implement HealthIndicator, ping billing partner API — return Health.up() or Health.down() with details. Readiness fails if critical dependency down.

Metrics and Prometheus?

Medium⭐ VIactuator▼

Answer

Micrometer registry — HTTP latency, JVM memory, Hikari pool. Add micrometer-registry-prometheus, scrape /actuator/prometheus. Grafana alerts on error rate and pool usage.

Logging and MDC correlation ID?

Mediumactuator▼

Answer

Filter reads X-Correlation-Id (or generates UUID), puts in MDC, log pattern includes %X{correlationId}. Trace one request across microservices — essential for Vodafone incident triage.

Graceful shutdown?

Medium⭐ VIactuator▼

Answer

server.shutdown=graceful — stop accepting new requests, finish in-flight, then close context. K8s preStop hook + adequate terminationGracePeriodSeconds.

What Actuator endpoints to expose in production?

Medium⭐ VIactuator▼

Answer

Typically: health, prometheus, maybe info. Never public: env, beans, heapdump, shutdown. Network policy + auth on management port.

JVM flags for Spring Boot in containers?

Hardactuator▼

Answer

-XX:MaxRAMPercentage=75.0 respects cgroup memory limit. Container-aware ergonomics in Java 11+. Avoid fixed huge -Xmx exceeding pod limit → OOMKilled.

Jenkins post-deploy smoke test?

Easyactuator▼

Answer

Pipeline curls /actuator/health or lightweight API after deploy — fail fast before full traffic. Matches your Optima Jenkins experience.

spring-boot-devtools in production?

Easyactuator▼

Answer

Never. Dev-only classpath restart and live reload. Not packaged in prod build; exclude from Docker image.

Answer

What is @MockBean?

Medium⭐ VItesting▼

Answer

Replaces bean in Spring test context with Mockito mock — use in @WebMvcTest to mock service layer when testing controller mappings and JSON responses.

Testcontainers vs H2?

Medium⭐ VItesting▼

Answer

H2 fast but different SQL dialect from Oracle/PostgreSQL prod. Testcontainers spins real DB in Docker — catches migration and query issues. Worth it for repository integration tests.
