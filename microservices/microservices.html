Microservices vs monolith — trade-offs?

Easy⭐ VIfundamentals▼

📌 Revision keywords

  • Microservices:
  • monolith
  • ACID
  • CI
  • CD
  • API
  • Telco

Brief explanation

In simple terms: Compare both sides and know when to use each in interviews.

Monolith: single deployable, simple debugging, ACID transactions in one DB. Microservices: independent deploy/scale per service, team ownership per bounded context.

Costs of microservices

  • Distributed failures, networking latency
  • Data consistency across services harder
  • Need observability, CI/CD maturity, API contracts

When to split

When scaling, release cadence, or team boundaries are blocked by monolith — not because it is fashionable.

Your angle

Telco BSS is already distributed; you worked integration microservices (Camel) around legacy cores, not a greenfield Netflix stack.
